# 📷 Instruções de Acesso às Imagens

Caso seu nome **não esteja no site** ou você **não consiga ver a sua imagem direito**, siga os passos abaixo:

---

### 📌 Como acessar sua imagem:

1. Copie o seguinte link e cole no seu navegador:
   `https://marquezz-sys.github.io/imagens/`

2. Logo após a barra (`/`), digite o seu **código de acesso**, que segue o padrão:  
   **`seunome.png`**

> **Exemplo de uso:**  
> Se o seu nome for **Marcos**, o link final no navegador ficará assim:  
> `https://marquezz-sys.github.io/imagens/marcos.png`
