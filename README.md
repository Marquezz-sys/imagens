# 📷 Instruções de Acesso às Imagens

Caso seu nome **não esteja no site** ou você **não consiga ver a sua imagem direito**, siga os passos abaixo:

---

### 📌 Como acessar sua imagem:

1. Copie o seguinte link e cole no seu navegador:
   `https://marquezz-sys.github.io/imagens/`

2. Logo após a barra (`/`), digite o seu **código de acesso**, que segue o padrão:  
   **`seunome.png`**

**Lembre-se:**  
Para adicionar você ao site, você tem que dizer ao responsável o nome que deseja, se por exemplo o nome que você colocou no cadastro é **Marcos**, o link final no navegador ficará assim:  
 `https://marquezz-sys.github.io/imagens/marcos.png` ou `https://marquezz-sys.github.io/imagens` e procurar seu usuário
